# tax-utilities

[![Tests](https://github.com/mrensan/tax-utilities/actions/workflows/test.yml/badge.svg)](https://github.com/mrensan/tax-utilities/actions/workflows/test.yml)

`tax-utilities` is an open-source collection of CLI tools and mathematical scripts designed to solve complex German tax
scenarios, allocation edge cases, and personal finance breakdowns.

---

## Tool Highlight: Joint Tax Refund Splitter (`tax_split.py`)

### Overview & Purpose

When a married couple in Germany (*Ehegatten*) files a joint tax return (*Zusammenveranlagung*), the tax office (*Finanzamt*) 
calculates a single combined tax refund (*Steuererstattung*). For couples working in **Tax Class 4/4** (*Steuerklasse 4/4*), 
splitting this refund fairly is notoriously complex:

1. **Progressive Tax Brackets (*Einkommensteuertarif*):** Germany uses a progressive tax scale. Higher earners pay a significantly 
higher effective percentage on their top income.
2. **Joint Splitting Advantage (*Ehegattensplitting*):** Joint filing creates a tax discount by blending two incomes. 
This advantage is disproportionately generated by the higher-earning spouse.
3. **Individual Work Costs (*Werbungskosten*):** Income-related expenses directly reduce individual taxable income and 
generate extra refund value.

A simple 50/50 split or a linear income-ratio calculation fails to account for these dynamics. `tax_split.py` uses a 
**Hybrid Progressive Virtual-Tax Model** to determine a mathematically equitable percentage share of the joint refund for both partners.

## Parameter Input & Documentation Guide

To run the script, extract the required figures from your official German tax documents:

| Parameter | Script Flag | Description | German Document & Line Reference |
| :--- | :--- | :--- | :--- |
| **$A$** | `-a`, `--income-man` | Man's Gross Income | **Lohnsteuerbescheinigung**: Line 3 (*Bruttoarbeitslohn*) |
| **$B$** | `-b`, `--income-woman` | Woman's Gross Income | **Lohnsteuerbescheinigung**: Line 3 (*Bruttoarbeitslohn*) |
| **$C$** | `-c`, `--costs-man` | Man's Work Expenses | **Einkommensteuererklärung / Anlage N** (*Werbungskosten*) |
| **$D$** | `-d`, `--costs-woman` | Woman's Work Expenses | **Einkommensteuererklärung / Anlage N** (*Werbungskosten*) |
| **$TAX1$** | `-t`, `--tax1` | Total Initial Tax Withheld | Sum of withheld taxes from both payslips, or **Einkommensteuerbescheid**: *Anrechnung von Lohnsteuer* |
| **$RETURN$** | `-r`, `--return-amount` | Total Joint Refund | **Einkommensteuerbescheid**: Page 1 (*Erstattung / Guthaben*) |
| **$T_{Man}^{exact}$** | `--exact-tax-man` | *(Optional)* Exact Tax Deducted (Man) | **Lohnsteuerbescheinigung**: Sum of Line 4 (*Lohnsteuer*), Line 5 (*Soli*), and Line 6 (*Kirchensteuer*) |
| **$T_{Woman}^{exact}$** | `--exact-tax-woman` | *(Optional)* Exact Tax Deducted (Woman) | **Lohnsteuerbescheinigung**: Sum of Line 4 (*Lohnsteuer*), Line 5 (*Soli*), and Line 6 (*Kirchensteuer*) |

> **Note on Church Tax & Soli:** If you pay Church Tax (*Kirchensteuer*) or Solidarity Surcharge (*Solidaritätszuschlag*), add them to Line 4 on your *Lohnsteuerbescheinigung* when supplying exact tax parameters.

## Installation & Execution

### Prerequisites

* Python 3.10 or higher.
* Uses standard library modules (`argparse`, `sys`). No third-party packages required.

### Setup

```bash
git clone https://github.com/mrensan/tax-utilities.git
cd tax-utilities
```

### Running the Script

**Example 1: Standard Execution (Estimating initial tas distribution)**

If you only have gross incomes, work costs, combined tax paid, and the return amount:

```bash
python tax_split.py \
  -a 72500 \
  -b 48000 \
  -c 2150 \
  -d 3400 \
  -t 22055.80 \
  -r 3120.40
```

**Example 2: Advanced Execution (Using exact Payslip Tax Amounts)**

Passing exact tax withholdings (`--exact-tax-man` and `--exact-tax-woman`) produces the most accurate allocation by factoring
in precise tax brackets:

```bash
python tax_split.py \
  -a 72500 \
  -b 48000 \
  -c 2150 \
  -d 3400 \
  -t 22055.80 \
  -r 3120.40 \
  --exact-tax-man 15240.50 \
  --exact-tax-woman 6815.30
```

### Sample Output

```text

Tax Refund Split Calculator (Progressive + Costs Adjusted)
--------------------------------------------------
Total Refund:   €3,120.40

Man's Share:    €1,982.33 (63.5%)
Woman's Share:  €1,138.07 (36.5%)
```

## Mathematical Methodology

The script executes a 5-step **Hybrid Progressive Virtual-Tax Allocation:**

### Step 1: Base Withholding Normalization

When exact withholding amounts $T_{Man}^{exact}$ and $T_{Woman}^{exact}$ are provided, they are scaled slightly to match 
$TAX1$ exactly. This reconciles minor line-item rounding or church tax variances:

$$Paid_{Man} = TAX1 \times \left( \frac{T_{Man}^{exact}}{T_{Man}^{exact} + T_{Woman}^{exact}} \right)$$

$$Paid_{Woman} = TAX1 \times \left( \frac{T_{Woman}^{exact}}{T_{Man}^{exact} + T_{Woman}^{exact}} \right)$$

(If exact taxes are omitted, the script defaults to a gross income ratio: $Paid_{Man} = TAX1 \times \frac{A}{A + B}$).

### Step 2: Individual Progressive Tax Rate Determination

Calculate each partner's effective pre-refund tax rate based on their individual income tier:

$$r_{Man} = \frac{Paid_{Man}}{A}, \quad r_{Woman} = \frac{Paid_{Woman}}{B}$$

### Step 3: Net Taxable Base & Virtual Tax Liability

Deduct individual work costs ($C$ and $D$) from gross incomes ($A$ and $B$) to derive net taxable bases, then apply individual 
effective rates to compute "Virtual Tax Liabilities":

$$Net_{Man} = \max(0, A - C), \quad Net_{Woman} = \max(0, B - D)$$

$$V_{Man} = Net_{Man} \times r_{Man}, \quad V_{Woman} = Net_{Woman} \times r_{Woman}$$

### Step 4: Final Tax Allocation

Calculate total actual tax owed by the household ($TAX1 - RETURN$), then divide it according to the ratio of individual 
Virtual Tax Liabilities:

$$FairTax_{Man} = (TAX1 - RETURN) \times \left( \frac{V_{Man}}{V_{Man} + V_{Woman}} \right)$$

$$FairTax_{Woman} = (TAX1 - RETURN) \times \left( \frac{V_{Woman}}{V_{Man} + V_{Woman}} \right)$$

### Step 5: Net Refund & Percentage Shares

Each partner's fair refund share is what they paid upfront minus their fair share of the final tax bill:

$$Refund_{Man} = Paid_{Man} - FairTax_{Man}$$

$$Refund_{Woman} = Paid_{Woman} - FairTax_{Woman}$$

$$\text{Man %} = \left( \frac{Refund_{Man}}{RETURN} \right) \times 100, \quad \text{Woman %} = \left( \frac{Refund_{Woman}}{RETURN} \right) \times 100$$
